# Anime Atlas

Anime Atlas, yalnızca HTML, CSS ve JavaScript ile hazırlanmış statik bir anime keşif sitesidir. GitHub Pages üzerinde yayımlanabilir; sunucu veya veritabanı gerektirmez.

## Dosyalar

- `index.html` — Sayfa içeriği ve anime ayrıntı penceresi
- `styl.css` — Görünüm ve mobil düzen
- `script.js` — Anime kataloğu, arama, filtreler ve izleme listesi

## Siteyi açma

`index.html` dosyasını tarayıcıda aç. Anime kartına tıklayınca yeni sekmede YouTube araması açılır. YouTube'daki yayın ve erişim durumu videoya, bölgeye ve zamana göre değişebilir.

## Anime içerikleri

Site anime bölümlerini barındırmaz. Kart tıklamaları YouTube'da başlığa göre arama yapar; sonuçlardan izlemek istediğin videoyu seçebilirsin. YouTube'daki içeriklerin bulunabilirliği ve izlenebilirliği değişebilir.

## GitHub Pages

Bu üç site dosyasını GitHub deposunun kök dizinine koy. Depo ayarlarında **Pages** bölümünden `main` dalını ve `/ (root)` klasörünü seç. `README.md` bu adımları anlatır; yayımlanacak site için zorunlu değildir.

## İçerik hakları

Anime adları ve tanıtım metinleri keşif amacıyla listelenir. Bölüm videolarını indirme, yeniden barındırma veya dağıtma izni bu projeyle verilmez.
